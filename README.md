# Portfolio Website Template

A clean, responsive personal portfolio template in plain HTML, CSS and
JavaScript. No frameworks, no build step — just edit and publish.

## Features

- Sticky nav, hero section, about, projects and contact
- Project cards rendered from a simple list in `script.js`
- Responsive layout that works on phones and desktops
- Easy to host free on GitHub Pages, Netlify or Vercel

## How to use

1. Replace "Your Name", the tagline and the about text in `index.html`
2. Edit the `PROJECTS` list in `script.js` with your own projects
3. Update the contact links, then open `index.html` to preview

## Publish on GitHub Pages

Push this repo to GitHub, then go to **Settings → Pages → Deploy from branch**
and choose the `main` branch. Your site goes live at
`https://<username>.github.io/<repo>/`.
